- 室内净面积 150.5 ㎡ + 阳台 13.6 ㎡ + 墙体 + 分摊 = 建筑面积 262 ㎡（公摊口径），不能用建面直接减净面积求公摊；精确套内面积以《房屋测绘报告》为准。
- 关于"客厅剪力墙保留"：原两套（04/05）的分户墙应在 x≈5.3–5.7 m 一列。原图在这一列上用**特殊填充**画了两个小构件：客厅北墙端的空心矩形（约 400×890，x 5260–5655 / y 6910–7800）和卧室区北墙端的点状填充块（约 430×480）；多功能室北墙端在原图上是留空的开口（约 350）而不是柱；走道内原以为的短墙实为推拉门。因此客厅与多功能室之间可确认的"保留构件"只有那个 400×890 的空心矩形（柱或矮墙），其余墙段原图均按普通实墙绘制，是否为剪力墙无法从本图判断，需以结构竣工图为准。
- 流线：卧室的唯一出入口是面向走道西段的门洞，走道西段通过推拉门与走道东段相连，再经洞口到餐厅；即卧室 + 客卫A 构成一个带前室的套房。

**重绘的可信度分级**

- 外围尺寸链、轴网：来自原图标注，可信。
- 墙/玻璃分段、门洞、家具位置：按原图像素比例推算（标定 x 0.0390 px/mm、y 0.0385 px/mm），误差约 ±200 mm；原图分辨率仅 1280×960，1 px ≈ 26 mm。
- 柱/墙垛的判读仅凭原图的特殊填充，**非结构图**。
- 图中 18550×17350 的外轮廓含公共走道与电梯厅（核心筒约 5.65 m × 11.65 m），**不是**该套房的建筑面积范围。

## 与早前"镜像拼合示意"的差异

早前 `3C_0405打通262_镜像拼合示意.png` 是按两套 C1-131 简单镜像拼接得到的；官方 262 图是开发商重新设计的打通方案（主卧套房+衣帽间、多功能室、西厨/中厨、两个客卫、儿童房、家政间、三个阳台），布局与镜像示意**不一致**，以官方 262 图为准。
