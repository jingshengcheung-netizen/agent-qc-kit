**原图标注的外围尺寸链（mm，重绘严格照抄）**

- 横向（轴 1→9）：1300 + 2900 + 1900 + 1700 + 3000 + 2100 + 2950 + 2700 = **18550**
- 纵向（轴 A→J）：2400 + 1300 + 2000 + 1900 + 2650 + 1250 + 1400 + 2300 + 2150 = **17350**

**重绘的可信度分级**

- 外围尺寸链、轴网：来自原图标注，可信。
- 室内隔墙、门窗、家具位置：按原图比例推算（标定：x 方向 0.0390 px/mm，y 方向 0.0385 px/mm），误差约 ±200 mm。
- 剪力墙（粗黑线）：按原图线宽推测，**非结构图**；其中客厅/多功能室之间约 x=5.5 m 处保留的短墙段与用户在售楼处了解的"客厅剪力墙部分保留"相符，但精确位置需以结构竣工图为准。
- 房间内的"约 a×b"为轴线尺寸估算（m），不是套内净尺寸（需各减去墙厚）。
- 图中 18550×17350 的外轮廓含公共走道与电梯厅（核心筒约 5.65 m × 11.65 m），**不是**该套房的建筑面积范围。

## 与早前"镜像拼合示意"的差异

早前 `3C_0405打通262_镜像拼合示意.png` 是按两套 C1-131 简单镜像拼接得到的；官方 262 图是开发商重新设计的打通方案（主卧套房+衣帽间、多功能室、西厨/中厨、两个客卫、儿童房、家政间、三个阳台），布局与镜像示意**不一致**，以官方 262 图为准。
