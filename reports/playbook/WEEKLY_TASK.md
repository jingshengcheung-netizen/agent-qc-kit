# 每周一定时任务手册

本聊天只绑定一份固定工作：《中国私募合规周报》。

- 频率：每周一
- 时间：北京时间 08:00（UTC 00:00）
- cron：`0 0 * * 1`
- 定时器名称：`china-pe-compliance-weekly`
- 交付方式：在本聊天更新，把周报发给用户即可
- 覆盖区间：上一自然周，周一至周日
- 不生产每日晨报、不合规日更

## 内容硬约束

1. 官方来源优先。媒体只作线索。
2. 分开记录发布日、决定日、公开日、生效日、截止日。
3. 每条归入：新规则/统一流程、执法个案、监管指导或官方解读、征求意见稿、已发布即将生效。
4. 不把地方个案写成全国口径变化。
5. 没有新规则就写「未发现经官方确认的新增全国性规则」，不拿旧闻凑篇幅。
6. AMBERS 没有协会公告或可核实统一调整，就不写流程变化。
7. 重要数字、文号、截止日期带原文链接。
8. 行动清单写清责任职能、办理事项、期限。
9. 跑门禁：`PYTHONPATH=src python3 -m agent_qc_kit <稿件>`。
10. commit、push，更新本分支 PR；然后在聊天里把结论和 HTML 路径发给用户。
